# Student Performance Analysis & Prediction System

A complete data pipeline that analyzes student marks, visualizes performance trends, and predicts Pass/Fail results using Machine Learning.

## What it does

- Reads and cleans student marks data (handles missing values)
- Calculates subject-wise and per-student averages
- Identifies top/weak performers and overall pass percentage
- Visualizes performance using bar charts and boxplots
- Trains a Logistic Regression model to predict Pass/Fail
- Takes live input for a new student and returns a prediction

## Tech Stack

- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- scikit-learn

## How to run

1. Clone this repository
2. Install dependencies: `pip install pandas numpy matplotlib seaborn scikit-learn`
3. Open `student_performance.ipynb` in Jupyter Notebook or VS Code
4. Run all cells in order

## What I learned

Working through this project taught me the full data science pipeline hands-on — from realizing a Pandas operation doesn't change your data unless you assign it back, to understanding why models need consistent train/test splits, to seeing how a boxplot reveals patterns an average alone can't show.
